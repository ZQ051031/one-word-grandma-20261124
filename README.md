One word a grandma would text about AI: **Witchcraft**.

A grandma faced with a machine that talks back would not reach for tech
jargon. She would call it what every new marvel has always been called at
her kitchen table: witchcraft. Warm, a little baffled, and funny in a single
word — exactly how she would text it.

## Entry

`main.py` (Python standard library only) writes the single word
`Witchcraft` (10 characters, no trailing newline) to `entry.txt` in the
output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run

```sh
python3 main.py
```
